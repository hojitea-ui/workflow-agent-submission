# 보고서·과제 글 검수 에이전트

## 제품의 목적
직접 쓴 보고서나 과제 글을 넣으면 구조·논리·근거 부족·비약을 찾아 우선순위와 수정 방향을 제안한다. 사용자가 고른 방향대로 필요한 자료를 검색해 그 부분만 고치고, 고친 결과가 처음 지적한 문제를 해결했는지 다시 검수한다. 자료가 부족하면 지어내지 않고 부족한 부분을 표시한다. 가장 작은 범위로 만든 버전이다.

**이번 범위**: 입력 → AI 판단 → 사람 결정 → 도구 행동 → 검수·산출물까지가 처음 설계(STEP-13-1)다. 라운드(최대 3번), 새 문제 중요도, 보류 목록과 자료 붙여 넣기는 처음에 없다가 사용하면서 막혀서 추가했다(이유와 결과는 VALIDATION.md 4번).

(이 문서는 카드뉴스 에이전트 PRD를 검수 워크플로로 바꾼 것이다. 서버·DB·Claude CLI 연결·진행 상태 폴링 같은 뼈대는 그대로 쓰고 카드·이미지·글자 합성은 모두 뺐다.)

## 워크플로 (STEP-13-1 설계)
| 설계한 부분 | 내용 |
|---|---|
| 입력 | 과제 제목(주제), 제출 조건(분량·종류·독자 등, 선택), 글 본문(붙여넣기 또는 .md/.txt 올리기). |
| AI 판단 | 글을 문단 번호(P1, P2…)로 나누어 구조·논리·근거 부족·비약·조건 미충족을 최대 5개 찾는다. 우선순위를 매기고, 지적마다 해당 문장(원문 그대로 인용), 문제 설명, 중요한 이유, 수정 방향 2개와 추천을 보인다. |
| 사람 결정 | 지적마다 방향 A/B, 직접 쓴 방향, 건너뛰기 중 하나를 고른다. 이미 입력한 제목·조건은 다시 묻지 않는다. |
| 도구 행동 | 고른 방향에 자료가 필요하면 WebSearch·WebFetch로 찾고, 해당 문단만 고친다. 고르지 않은 문단은 그대로 둔다. 자료를 못 찾으면 고치지 않고 그 자리에 "자료 보강 필요"를 표시한다. |
| 검수와 산출물 | 처음 지적이 해결됐는지(해결/일부/미해결/자료 부족) 다시 판단하고 고친 문단 말고는 바뀌지 않았는지 검사한다. 수정본(`final.md`)과 검수 리포트(`review_report.md`)를 내려받는다. |

## 수용 조건
1. 지적마다 원문에 실제로 있는 문장을 인용한다. 원문에 없는 인용은 한 번 다시 쓰게 하고, 그래도 없으면 분석을 실패로 처리한다(지어낸 인용으로 통과시키지 않는다). 구조처럼 인용할 문장이 없는 지적은 모델이 인용을 비우고 문단만 가리킬 수 있다.
2. 사용자가 고르기 전에는 글을 고치지 않는다. 고르지 않은 문단은 수정본에서 한 글자도 바뀌지 않는다.
3. 수정에 쓴 근거는 실제 검색·열람 기록에 있는 주소만 쓴다. 근거 없는 수치를 넣지 않는다.
4. 자료가 부족하면 완료로 표시하지 않고 부족한 부분을 수정본과 리포트에 표시한다.
5. 새로고침해도 입력·지적·선택·결과가 유지된다. 검색 불가·로그인 필요·형식 오류는 원인과 다시 시도를 보여 준다.
6. **근거를 확인할 수 없으면 추측하거나 그럴듯하게 만들어 채우지 않는다.** 확인된 내용(출처가 붙은 것)과 확인하지 못한 내용(보류)을 구분하고, 보류한 내용마다 "무엇을 확인하지 못했는지"와 "필요한 추가 자료"(어떤 문헌·통계인지 구체적으로)를 글과 리포트에 적는다. 근거가 일부만 있으면 그 부분만 고치고 나머지는 보류한다. 사용자가 보류 항목에 자료를 붙여 넣으면 그 자료에 있는 내용만 근거로 써서 이어서 고친다(출처는 "사용자 제공 자료").
7. 결과는 고치기 전·후를 삭제(취소선)·추가(굵게)로 표시하고, 고친 내용(문단 단위와 수정본 전체)을 복사할 수 있다. 긴 글도 화면 밖으로 넘치거나 중간에서 잘리지 않는다.
8. 재검수는 쓴 출처와 기계 검사 결과를 보고 판단한다. 새로 생긴 문제는 중요도와 함께 보여 주고, 중요도 높음·보통은 같은 흐름으로 이어서 고칠 수 있다(라운드, 최대 3번). 낮은 문제는 참고로 접어 둔다.
9. 남은 문제(새 문제 중요도별 개수, 미해결, 일부 해결, 자료 부족, 보류한 내용)를 결과와 리포트에 적고, 모두 해소됐을 때만 "쓸 만한 상태"로 표시한다.

## 하지 않는 것 (가장 작게)
- Word(.docx)·PDF·HWP 입력·출력, 3번을 넘는 반복, 문장 단위 되돌리기, 글 전체 재작성, 다국어, 사용자 계정.
- 이미지와 카드 제작(카드뉴스 쪽 기능).
