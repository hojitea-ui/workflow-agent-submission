- 선택한 방향: 비교 기준 재설정
- 방향 설명: 장르 차이 대신 매화를 다루는 태도, 곧 시는 초월적·이상화, 그림은 사실적·질감 중심 같은 두 작품의 실제 표현 방식 차이를 기준으로 삼아 서술한다. 비교 대상이 대응되므로 이쪽이 낫다.
