# 보고서·과제 글 검수 에이전트

직접 쓴 보고서나 과제 글을 넣으면 구조·논리·근거 부족·비약을 찾아 수정 방향을 제안하고, 고른 방향대로 자료를 검색해 그 문단만 고친 뒤 재검수합니다. 자료가 부족하면 지어내지 않고 부족한 부분을 표시합니다. 가장 작은 범위로 만든 버전입니다(PRD.md, DECISIONS.md 참고).

## 준비물
- Windows, Python 3.11 이상, 로그인된 Claude CLI(`claude`). 터미널에서 `claude`를 한 번 실행해 로그인해 두세요. 앱은 로그인 정보를 다루지 않습니다.

## 처음 한 번만
PowerShell에서 이 폴더(`report-review-kit`)로 이동해 실행합니다(아래 `cd`는 압축을 푼 위치에서 시작한다고 봅니다).

```powershell
cd report-review-kit
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 켜기
```powershell
cd report-review-kit
$env:PYTHONUTF8 = "1"
.\.venv\Scripts\python.exe run.py
```
브라우저에서 `http://127.0.0.1:8770`을 엽니다. 8770번을 다른 프로그램이 쓰면 8771부터 빈 번호로 시작하고 그 주소를 창에 알려 줍니다(`--port 번호`로 직접 지정도 가능). 끄려면 실행 창에서 `Ctrl+C`.

## 쓰는 법
1. **글 넣기**: 과제 제목, 제출 조건(선택: 분량·종류·읽는 사람 등), 글 본문을 붙여 넣거나 `.md`/`.txt` 파일을 올리고 **검수 시작**. 문단은 빈 줄로 나눕니다.
2. **지적 확인**: 1분 안팎 뒤 중요한 순서로 지적이 나옵니다(최대 5개). 지적마다 글에서 그대로 가져온 문장, 문제, 왜 중요한지, 수정 방향 두 가지(추천 표시)가 보입니다.
3. **방향 고르기**: 지적마다 A / B / 직접 쓴 방향 / 건너뛰기 중 고릅니다. 이미 입력한 제목·조건은 다시 묻지 않습니다.
4. **수정과 재검수**: **선택한 N개 수정하고 재검수**를 누르면, 자료가 필요한 방향은 웹에서 검색·열람해 근거를 붙여 그 문단만 고칩니다. 몇 분 걸릴 수 있고 화면에 검색 중인 내용이 보입니다. 중간에 **취소**할 수 있습니다.
5. **새 문제 이어서 고치기(선택)**: 재검수가 이번 수정이 새로 만든 문제를 중요도(높음/보통/낮음)와 함께 알려 줍니다. 높음·보통은 "이 문제도 고치기"를 체크하고 **선택한 새 문제 고치기**를 누르면 고친 글에서 이어서 수정 방향을 고르는 다음 라운드(최대 3번)가 시작됩니다. 낮음은 접혀 있는 참고입니다. 중요도 높은 새 문제·미해결·자료 부족이 없으면 "쓸 만한 상태입니다"가 뜹니다.
6. **결과 확인**: 지적마다 해결 / 일부 해결 / 미해결 / 자료 부족 / 건너뜀과 고치기 전·후, 근거 출처, 확인이 필요한 수치, 새로 생긴 문제가 나옵니다. **수정본(final.md)**과 **검수 리포트(review_report.md)**를 내려받습니다. 파일은 `data\projects\<프로젝트 ID>\outputs\`에도 저장됩니다.

## 알아 둘 점
- **근거를 확인하지 못하면 추측하지 않고 보류합니다.** 확인된 내용(출처가 붙은 것)과 확인하지 못한 내용을 나눠, 보류한 내용마다 "필요한 추가 자료"(어떤 문헌·통계인지)를 화면과 리포트에 적고 글에는 `⚠[자료 보강 필요: …]` 표시만 남깁니다. 보류 항목 아래 칸에 구하신 자료(원문 발췌·수치·메모)를 붙여 넣고 **붙여 넣은 자료로 보류 항목 다시 고치기**를 누르면, 그 자료에 있는 내용만 근거로 써서 이어서 고칩니다(출처는 "사용자 제공 자료"로 표시됩니다). 붙여 넣은 자료가 보류한 내용과 상관없으면 모델이 쓰지 않고 다시 보류할 수 있습니다.
- 결과 화면은 고치기 전·후를 **삭제 취소선 / 추가 굵은 초록**으로 비교해 보여 주고(같은 글이 긴 곳은 줄임), 고친 뒤 글과 수정본 전체를 **복사** 버튼으로 가져갈 수 있습니다. 리포트(.md)에도 같은 변경 표시(`~~삭제~~`, `**추가**`)가 들어갑니다.
- **고르지 않은 문단은 한 글자도 바뀌지 않습니다.** 앱이 직접 비교해서 바뀐 문단이 있으면 결과 화면에 경고합니다.
- **자료를 못 찾으면 고치지 않고** 그 자리에 `⚠[자료 보강 필요: …]`를 남기며 "자료 부족"으로 셉니다. 수정본 끝에도 부족한 부분 목록이 붙습니다.
- 수정에 쓴 출처 주소는 이번 검색·열람 기록에 있는 것만 인정합니다. 그래도 **출처 내용이 문장을 정말 뒷받침하는지는 직접 확인**해 주세요(앱은 페이지를 다시 열어 대조하지 않습니다). 근거에서 못 찾은 수치는 "확인 필요"로 표시됩니다.
- 같은 문단을 가리키는 지적을 둘 이상 고르면 차례로 고치며, 마지막 결과가 그 문단의 최종본입니다.
- 라운드는 최대 3번입니다. Word(.docx)·PDF·HWP 입력과 출력, 문장 단위 되돌리기는 없습니다(한글 문서는 텍스트로 저장해 올리세요. 문단 사이에 빈 줄이 있어야 문단이 나뉩니다).
- 글과 모델 응답은 `data\`에 저장됩니다(폴더째 지우면 기록이 사라집니다).

## 자주 막히는 곳
| 증상 | 이유와 해결 |
|---|---|
| "Claude CLI 로그인이 필요합니다" | 터미널에서 `claude`를 실행해 `/login`으로 로그인한 뒤 화면의 다시 시도(분석은 "다시 분석", 수정은 같은 버튼)를 누르세요. |
| "웹 검색을 쓰지 못해 자료를 찾을 수 없습니다" | 일시 오류이거나 계정에 웹 검색 권한이 없는 경우입니다. 잠시 뒤 다시 시도하세요. 선택한 방향은 그대로 남아 있습니다. |
| "Claude 답변 형식이 올바르지 않습니다" | 모델이 약속한 형식을 두 번 어긴 것입니다. 다시 시도하세요. |
| 서버를 껐다 켜니 "작업이 중단되었습니다" | 진행 중이던 작업만 끊긴 것입니다. 분석 결과와 선택은 남아 있으니 같은 버튼으로 다시 시작하세요. |

## 개발자용: 테스트
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests
```
테스트는 가짜 `claude`(`tests/fake_claude.py`)와 임시 폴더를 써서 실제 모델도 사용자 data도 건드리지 않습니다. 환경 변수: `RV_CLAUDE_MODEL`(기본 sonnet), `RV_CLAUDE_EFFORT`(기본 medium), `RV_CLAUDE_TIMEOUT`(초, 기본 600), `RV_DATA_DIR`(저장 폴더), `RV_CLAUDE_CMD`(시험용 명령 교체).
