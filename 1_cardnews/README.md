# 카드뉴스 워크플로 제작 키트
이 자료는 완성 앱이 아니라, 코딩 AI와 앱을 만들기 위한 PRD와 검수 자료입니다.

1. 압축을 풀고 폴더를 Claude Code 또는 OpenCode로 엽니다.
2. 아래 요청을 입력하고 AI의 질문에 답합니다.

> PRD.md를 읽고 카드뉴스 에이전트를 만들어 줘. 미정인 부분은 먼저 물어보고, 브라우저에서 후보를 고르고 질문에 답하는 흐름부터 보여 줘.

3. 아래 "앱 실행하기"를 따라 실행하고 안내받은 로컬 주소를 엽니다.
4. `AI 최신소식`을 입력하고 ACCEPTANCE.md를 확인합니다.
5. 만든 흐름을 자신의 주제로 바꾸고 달라져야 할 판단·도구·검수 조건을 PRD에 반영합니다.

실행 엔진은 Claude Agent SDK, Claude CLI, OpenCode CLI 중 하나로 시작합니다. 이미지 생성에는 공식 Antigravity CLI `agy`를 사용합니다. 설치되어 있다는 것과 실제 로그인·검색·이미지 생성 권한이 있다는 것은 다릅니다. 사용할 계정에서 각 기능을 확인하세요.

공식 사용법과 카드 형식 레퍼런스는 REFERENCES.md를 참고하세요.

---

## 앱 실행하기

현재 상태: **내려받기까지 동작합니다(최종 승인 + PNG·ZIP·출처 기록 내보내기)**. 주제 입력 → 웹 검색으로 후보 조사 → 후보 선택 → 원문 확인(심층 조사) → 질문 답변 → 조사 기록과 편집 제안 → **스토리보드(5-8장) 승인 → 카드마다 이미지 만들기**까지 만들고, 이어서 제목·본문 글자 올리기, 카드 수정, 최종 승인, 내려받기(PNG·ZIP)까지 동작합니다(아래 '써 보기' 8-10번).

- **기본은 실제 조사**입니다. 앱이 내 PC의 Claude Code(`claude` 명령)를 호출해 웹을 검색하므로 **모델 호출이 일어나고 한 단계에 1-2분쯤 걸립니다**(Claude 사용량이 소모됩니다).
- 모의 데이터로 화면만 보고 싶으면 `--engine mock`으로 켜세요(아래 "모의 데이터로 켜기"). 이때는 화면 맨 위에 "모의 데이터" 띠가 보입니다.

필요한 것: Windows, Python 3.10 이상(3.14.7에서만 실행해 봤습니다), 인터넷, 그리고 실제 조사를 하려면 **Claude Code 설치와 로그인**. 이미지를 SVG로 만들려면 **Edge 또는 Chrome**이 있어야 하고(없으면 자동으로 도형 도안으로 대체), 이 PC에서는 Edge로 확인했습니다. 로그인 확인은 터미널에서 `claude`를 한 번 실행해 보면 됩니다. 로그인이 안 돼 있으면 앱이 "로그인이 필요합니다"라고 알려 주고, 로그인은 직접 하셔야 합니다(앱은 로그인 정보를 다루지 않습니다).

### 처음 한 번만: 준비하기

1. **PowerShell을 엽니다.** 시작 메뉴에서 `PowerShell`을 검색해 엽니다.
2. **이 폴더로 이동합니다.** (이 README.md 파일이 있는 폴더입니다.)

   ```powershell
   cd 1_cardnews
   ```

3. **전용 파이썬 환경(.venv)을 만듭니다.** 이 PC의 다른 파이썬을 건드리지 않습니다. 몇 초 걸립니다.

   ```powershell
   python -m venv .venv
   ```

4. **필요한 부품을 설치합니다.** 1-2분 걸릴 수 있고, 끝나면 아무 오류 없이 프롬프트가 돌아옵니다.

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

### 켜기

1. 같은 PowerShell 창(위 폴더)에서 입력합니다.

   ```powershell
   .\.venv\Scripts\python.exe run.py
   ```

2. 아래처럼 주소가 나오면 켜진 것입니다. **이 창은 닫지 말고 그대로 두세요.** 닫으면 앱도 꺼집니다.

   ```
   엔진: Claude CLI (실제 웹 검색, 모델 호출이 일어납니다)
   브라우저에서 이 주소를 여세요:  http://127.0.0.1:8765
   끄려면 이 창에서 Ctrl+C 를 누르세요.
   ```

   8765번 포트를 다른 프로그램이 쓰고 있으면 `[안내] 8765번 포트가 사용 중이라 8766번으로 시작합니다`처럼 다른 번호가 나옵니다. 그때는 **화면에 나온 주소**를 여세요.

3. **웹 브라우저(Chrome, Edge 등)를 열고 주소창에** `http://127.0.0.1:8765` 를 입력합니다. 이 주소는 내 컴퓨터 안에서만 열립니다(다른 사람은 접속할 수 없습니다).

### 모의 데이터로 켜기 (모델 호출 없음)

```powershell
.\.venv\Scripts\python.exe run.py --engine mock
```

고정된 모의 후보로 화면 흐름만 확인합니다. 주제에 `부족`을 넣으면 후보가 3개만 나오는 "30일로 넓히기" 상황을, `실패`를 넣으면 첫 조사가 실패하고 "다시 시도"로 복구되는 상황을 볼 수 있습니다. 모의 엔진에서 만든 프로젝트는 계속 모의 데이터로 표시됩니다.

### agy 이미지 생성 켜기/끄기 (기본은 켜짐)

agy(Antigravity)의 이미지 도구는 **기본으로 켜져 있어** 이미지를 만들 때 agy를 먼저 시도합니다. 다만 agy는 이미지를 만들 때 **사용 한도를 크게 쓰므로**, 쓰고 싶지 않을 때는 서버를 켤 때 옵션으로 끕니다. 끄면 agy를 한 번도 실행하지 않고 바로 Claude(SVG, 안 되면 도형 도안)로 이미지를 만들고, 카드에 "agy를 쓰지 않았습니다"라고 표시합니다.

```powershell
.\.venv\Scripts\python.exe run.py --no-agy
```

환경 변수로 끌 수도 있습니다(같은 PowerShell 창에서 한 번만 설정하면 됩니다). `0`, `false`, `off`, `no`가 "끔"이고 그 밖의 값이나 설정이 없으면 "켬"입니다.

```powershell
$env:CARDNEWS_USE_AGY = "0"
```

환경 변수로 꺼 둔 것을 한 번만 다시 켜려면 `run.py --agy`를 씁니다. 서버를 켰을 때 창에 나오는 `agy 이미지 생성: 켜짐/꺼짐` 줄로 지금 상태를 알 수 있고, 승인 화면의 안내 문구도 상태에 따라 바뀝니다. **켜 둔 채로 이미지를 만들면 agy 사용 한도를 씁니다**(agy가 한 번 실패하면 같은 실행의 나머지 카드는 agy를 건너뛰고 Claude로 만듭니다).

### 써 보기

1. 주제에 `AI 최신소식`을 입력하고 **조사 시작**을 누릅니다. 조사 기준 시각과 기간(최근 7일)이 표시되고, 실제 엔진에서는 "검색 중: …", "원문 확인 중: 도메인"과 경과 시간이 보입니다. 1-2분 뒤 후보가 나옵니다(8-12개 안팎). 각 후보에는 게시일(확인 못 하면 "미확인"), 원문 링크, 선택할 가치, 불확실성이 있습니다. 검색 기록에 없는 출처나 기간 밖 자료는 앱이 걸러 냅니다.
2. 후보를 **1-3개** 체크합니다. 체크하면 바로 저장되어 새로고침(F5)해도 유지됩니다. 4개째는 막힙니다. (독자층이 다른 후보를 섞어 고르면 다음 단계에서 질문이 나올 가능성이 높습니다.)
3. **다음 단계: 심층 조사**를 누르면 선택한 후보의 원문을 읽는 동안 진행 상황이 보입니다. 독자에 따라 결과가 크게 달라진다고 판단하면 "어떤 독자에게 전달할까요?" 같은 질문이 나옵니다. 새로고침해도 질문이 남아 있고, `추천` 표시가 있어도 직접 고르기 전에는 답변이 아닙니다. 질문 없이 바로 결과가 나올 수도 있습니다(AI가 판단하며, 이유는 "추천 형식"에 적힙니다).
4. 독자를 고르고(또는 직접 입력하고) **답변 보내기**를 누르면 같은 대화를 이어서 조사 기록(사실·출처·한계·상충하는 내용)과 편집 제안(독자·추천 형식·후킹 문구)이 나옵니다. 사실에는 `확인됨`/`업체 주장`/`공개 예정`/`미확인` 표시가 붙습니다.

5. 제안 화면 아래의 **스토리보드 만들기**에서 카드 형식(목록형/이야기형, AI 추천 표시)과 표지 후킹 문구를 고르고 만듭니다. 약 30초-1분 뒤 **5-8장 스토리보드**가 나옵니다. 장마다 **핵심 문장(메시지 하나)**, **본문**, **이미지 역할·그림 계획**, **출처 링크**가 있고, 모든 카드가 공유하는 **색 팔레트와 그림체**가 맨 위에 보입니다. 자료에서 찾지 못한 숫자가 있으면 카드에 경고가 붙습니다.
6. 마음에 안 들면 **변경 요청**(예: "3장 제목을 더 짧게")이나 **다른 형식으로 다시 만들기**를 누릅니다. 이전 스토리보드는 버전으로 남습니다. **승인하기 전에는 이미지를 만들지 않습니다.**
7. **이 스토리보드 승인하고 이미지 만들기**를 누르면 카드마다 설명용 이미지를 만듭니다. 기본으로 **agy**(Antigravity)의 내장 이미지 도구를 먼저 시도합니다(agy 사용 한도를 씁니다. 쓰고 싶지 않으면 `--no-agy`, 아래 "agy 이미지 생성 켜기/끄기"). agy가 이미지를 만들지 못하면(원인이 카드에 표시됩니다) **Claude CLI가 SVG 그림을 그리고**, 앱이 SVG를 검사(스크립트·글자·외부 링크 금지, 색은 스토리보드 팔레트로 통일)한 뒤 **Edge(없으면 Chrome)를 화면 없이 실행해 PNG로 바꿉니다.** Edge를 쓸 수 없거나 SVG가 검사를 통과하지 못하면 **Claude가 설계한 도형 도안을 Pillow로 그려** 대신 만듭니다. agy를 끈 경우에는 카드에 "agy를 쓰지 않았습니다"가 표시됩니다. 카드에는 만든 방식이 표시되고, 대체한 경우에는 그 이유가 표시됩니다. 만든 이미지는 모두 1080×1350 PNG로 저장되고 파일·형식·크기·위쪽 여백을 검사한 결과가 카드마다 보입니다. 이미지 안에는 글자가 없고 위쪽 30%는 제목을 올릴 자리로 비워 둡니다. 카드 하나가 실패해도 나머지는 계속 만들고, 실패한 카드는 **다시 시도**로 새 버전을 만듭니다(이전 버전은 보관).

8. 이미지가 만들어진 카드마다 **글자 올리기·모바일 미리보기** 버튼을 누르면 제목과 본문을 그림 위에 별도 글자로 올립니다. 오른쪽에 휴대폰 폭(390px) 미리보기가 보이고, 글자가 잘리거나(제목·본문), 위쪽 빈 영역을 넘어 그림과 겹치거나, 배경과 대비가 낮거나, 휴대폰에서 너무 작으면 **검사** 목록에 "고쳐야 함"으로 표시됩니다. 제목·본문 문구, 글자 크기(기본 자동 맞춤), 글자색, 본문 위치, 본문 바탕 띠 농도를 고쳐 가며 미리보기를 확인한 뒤 **이 모습으로 저장**을 누르면 `v<버전>inal.png`(1080×1350)로 저장됩니다. 그림 파일과 승인한 스토리보드는 바뀌지 않습니다. 한국어 글꼴은 Windows의 맑은 고딕을 쓰고, 다른 글꼴을 쓰려면 환경 변수 `CARDNEWS_FONT`(굵은 글꼴은 `CARDNEWS_FONT_BOLD`)에 경로를 지정하세요.

9. 카드 아래 **이 카드만 고치기** 칸에 요청을 적습니다. 예: "3번 카드의 본문이 길어. 핵심 조건을 유지하며 두 문장으로 줄여 줘"(글만 고치고 **그림은 그대로**), "그림이 이상해, 배경을 더 단순하게"(**그 카드 그림만** 새 버전으로 다시 만듦). 다른 카드는 바뀌지 않습니다. 고치면 최종 승인이 풀리니 다시 확인하세요. 수정 기록은 카드 아래에 남습니다.
10. 모든 카드에 글자를 올리고 검사를 통과하면 화면 아래 **최종 승인**이 열립니다. 승인한 뒤 **카드별 PNG·ZIP·출처 기록 내보내기**를 누르면 카드별 PNG, 전체 ZIP(`cardnews.zip`), 출처(`sources.md`), 이미지 사용 기록(`image_usage.md`)을 내려받을 수 있고, 파일은 `data\projects\<프로젝트 ID>\exports\`에도 저장됩니다. 내보낸 파일을 기준으로 **누락·글자 잘림·출처·날짜**를 자동으로 확인하고, 앱이 확인하지 못한 항목은 통과로 두지 않고 **"직접 확인 필요"와 내가 할 일**로 알려 줍니다(예: 출처 링크를 열어 카드 문장과 맞는지, 휴대폰에서 글자가 읽히는지).

작업 중 **취소** 버튼을 누르면 실행 중인 `claude`·`agy` 프로세스도 함께 종료됩니다. 만든 이미지 파일은 `data\projects\<프로젝트 ID>\cards\<카드>\v<버전>\image.png`에 있습니다.

> **agy 이미지 생성은 기본으로 켜져 있지만, 이 PC에서 성공을 확인하지 못했습니다.** 켜 두면 이미지를 만들 때마다 agy 사용 한도를 쓴다는 점을 알아 두세요. 지금까지 시험한 5번 모두 이미지가 만들어지지 않았습니다(4번은 agy의 이미지 도구가 `500 Internal Server Error`, 1번은 agy가 이미지 도구를 쓰지 않고 끝남. 가장 최근 시험은 카드 1장에 약 18.6만 토큰을 쓰고 9번 시도 모두 500이었습니다. 어느 경우도 agy 응답 상태는 SUCCESS인데 이미지가 없습니다). 그래서 그때는 Claude로 대신 만들었습니다. agy가 실제로 이미지를 만드는 경우는 아직 직접 보지 못했습니다(자세한 내용은 API_SPEC.md 10장). 카드의 "만든 방식"과 "대체 수단을 쓴 이유"(agy를 끈 경우 "agy를 쓰지 않았습니다") 안내에서 어떤 방식으로 만들어졌는지 확인할 수 있습니다.

### 끄기

- 앱을 켠 PowerShell 창을 클릭하고 **Ctrl+C**를 누릅니다. 프롬프트(`PS C:\...>`)가 돌아오면 꺼진 것입니다. 창을 그냥 닫아도 꺼집니다.
- 서버 프로세스를 강제 종료해도(Windows, 작업 관리자의 "작업 끝내기" 같은 방식) 앱이 띄운 `claude` 프로세스도 함께 끝납니다. 창을 닫는 경우는 따로 시험하지 않았습니다. 작업 관리자에 `claude`가 남아 있다면 다른 Claude 세션일 가능성이 높습니다(앱이 띄운 것은 명령줄에 `--restricted`가 들어 있습니다).
- 꺼도 저장한 프로젝트는 `data` 폴더에 남아 다시 켜면 이어집니다. 모의 작업이 진행 중일 때 껐다면 다시 켠 뒤 "이어서 진행 / 처음부터 다시" 선택이 나옵니다.

### 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `python`을 찾을 수 없다고 나옴 | Python이 설치돼 있지 않거나 PATH에 없습니다. python.org에서 설치할 때 "Add python.exe to PATH"를 체크하세요. |
| `cd`가 폴더를 못 찾음 | 폴더를 다른 곳에 두었다면 그 경로로 바꿔 입력하세요. 탐색기에서 폴더 주소창을 복사해 붙이면 됩니다. |
| `.venv\Scripts\python.exe`를 찾을 수 없음 | 위 "처음 한 번만" 3번을 아직 하지 않았습니다. |
| 주소가 열리지 않음 | 앱을 켠 창이 열려 있는지, 주소의 포트 번호가 창에 나온 번호와 같은지 확인하세요. |
| 포트 사용 중 오류(`--port` 지정 시) | 다른 번호로 지정하세요: `.\.venv\Scripts\python.exe run.py --port 8800` |
| "Claude CLI 로그인이 필요합니다" (`auth_required`) | PowerShell에서 `claude`를 실행해 로그인(/login)한 뒤 화면의 **다시 시도**를 누르세요. |
| "웹 검색을 쓰지 못해…" (`search_unavailable`) | 잠시 뒤 **다시 시도**하세요. 계속되면 Claude 계정에서 웹 검색을 쓸 수 있는지 확인하세요. 앱은 검색이 안 된 상태로 만든 후보를 쓰지 않습니다. |
| 카드에 "Claude 도형 도안 + Pillow(SVG 대체)"와 "대체 수단을 쓴 이유: Claude SVG…"가 보임 | SVG를 쓸 수 없어 도형 도안으로 대신 만든 것입니다. 이유에 "Edge나 Chrome을 찾지 못했습니다"가 있으면 Edge나 Chrome을 설치하거나(Windows 10/11에는 보통 Edge가 있습니다) `CARDNEWS_BROWSER`에 브라우저 경로를 지정하세요. "SVG 검증을 통과하지 못했습니다"면 Claude가 규칙에 어긋난 SVG를 낸 것이니 "이미지 다시 만들기"로 새 버전을 만들어 보세요. |
| 카드에 "agy를 쓰지 않았습니다"가 보임 | 정상입니다. agy를 꺼 둔 설정(`--no-agy` 또는 `CARDNEWS_USE_AGY=0`)이라 Claude(SVG 또는 도형 도안)로 만들었다는 뜻입니다. agy를 쓰고 싶으면 그 설정을 빼고 서버를 다시 켜세요(위의 "agy 이미지 생성 켜기/끄기"). |
| 카드에 "agy(Antigravity CLI)를 이 PC에서 찾지 못했습니다"가 보임 | 서버를 켠 터미널에서 agy를 찾지 못한 것입니다. 이제 PATH에 없어도 기본 설치 위치(`%LOCALAPPDATA%\agy\bin\agy.exe`)에서 찾습니다. 그래도 안 되면 환경 변수 `CARDNEWS_AGY`에 agy 실행 파일 경로를 지정하세요. |
| 카드에 "agy 이미지 도구가 오류를 돌려줬습니다: 500 …"가 보임 | agy 쪽(서비스) 문제입니다. 앱이 Claude 도안으로 대신 만들었으니 그대로 쓰거나, 나중에 카드의 "이미지 다시 만들기"로 agy를 다시 시도하세요. agy를 처음 한 번 기다리는 데 최대 3분쯤 걸릴 수 있고, 한 번 실패한 뒤에는 같은 실행의 나머지 카드에서 agy를 건너뜁니다. |
| 카드가 "실패"로 남음(agy와 Claude 도안 모두 실패) | 카드의 오류 메시지를 확인하고 `agy`·`claude`를 터미널에서 한 번씩 실행해 로그인 상태를 확인한 뒤 "이 카드 다시 시도"를 누르세요. |
| "Claude CLI(claude)를 이 PC에서 찾지 못했습니다" | Claude Code를 설치한 뒤 새 PowerShell 창에서 다시 켜세요. 모의 데이터로 보려면 `run.py --engine mock`. |
| 결과가 안 나오고 오래 걸림 | 실제 조사는 단계마다 1-2분, 길면 몇 분 걸립니다. 15분이 넘으면 앱이 자동으로 중단하고 오류를 보여 줍니다. |
| 처음부터 다시 하고 싶음 | 앱을 끄고 `data` 폴더를 삭제한 뒤 다시 켜세요(저장한 프로젝트가 모두 사라집니다). |

### 개발자용: 테스트 실행

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

테스트는 임시 폴더에 따로 저장하므로 `data` 폴더를 건드리지 않습니다. Claude CLI 테스트는 실제 모델 대신 `tests/fake_claude.py`(가짜 claude)를 실행하므로 **모델 호출이나 사용량 소모가 없습니다**. agy도 가짜(`tests/fake_agy.py`)만 쓰므로 **실제 agy 사용 한도를 쓰지 않습니다**. agy가 기본 켜짐이라, 모든 시험의 기본 agy 명령을 "즉시 실패하는 가짜"로 바꿔 두어 어떤 시험도 실제 agy에 닿지 않습니다. 브라우저 시험은 가짜 브라우저(`tests/fake_browser.py`)를 쓰고, 한 시험(`test_svg.py`)만 이 PC의 실제 Edge를 화면 없이 실행합니다(브라우저가 없으면 건너뜁니다). `httpx` 관련 경고 한 줄이 나올 수 있으며 결과에는 영향이 없습니다.

설정(필요할 때만): 환경 변수 `CARDNEWS_CLAUDE_MODEL`(기본 `sonnet`), `CARDNEWS_CLAUDE_EFFORT`(기본 `medium`), `CARDNEWS_CLAUDE_TIMEOUT`(초, 기본 900), `CARDNEWS_BROWSER`(SVG를 그릴 브라우저 실행 파일 경로, 기본은 Edge→Chrome 자동 탐색), `CARDNEWS_BROWSER_TIMEOUT`(초, 기본 90), `CARDNEWS_USE_AGY`(`0`/`false`/`off`/`no`이면 agy 끔, 설정이 없으면 켜짐).

설계 문서: 결정은 [DECISIONS.md](DECISIONS.md), API와 화면 흐름은 [API_SPEC.md](API_SPEC.md).
